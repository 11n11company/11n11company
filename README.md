## ✦ Overview
The official digital flagship and website for **11:11 COMPANY**. Built with an editorial monochrome aesthetic, high-contrast serif typography, and responsive micro-interactions.

## ✦ Tech Stack
- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS
- **Typography**: Cormorant Garamond & Inter (Google Fonts)
- **Icons**: Lucide React
- **Animations**: Framer Motion

## ✦ Getting Started Locally

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Installation
```bash
# Clone the repository
git clone https://github.com/11n11company/11n11company.git

# Navigate into project directory
cd 11n11company

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
npm run build
```
